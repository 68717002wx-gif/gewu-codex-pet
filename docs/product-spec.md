# gewu-codex-pet 产品规格

## 1. 项目定位

- 项目名称：`gewu-codex-pet`
- 角色名称：格物页
- 目标：制作一款桌面 Codex 宠物，第一版同步交付角色设定图、动作帧资产、可交互 Demo，并预留真桌面透明窗口与 Codex/CLI 状态联动能力。
- 工作区限制：所有产物必须位于当前项目目录内。

## 2. 参考约束

用户明确要求严格按照上传参考图中的形态和参数制作：

- 风格：参考图这种角色设定稿风；偏 3D 潮玩 / 软胶质感 / 可爱设定稿。
- 形态：拟人化文档/便签角色。
- 主体：米白色纸张身体。
- 外壳：深森林绿色包裹式外壳。
- 五官：大眼睛、小嘴、腮红。
- 四肢：短手短脚、圆润站姿。
- 视图：需要类似参考图中的正面、侧面、背面、俯视、仰视、多表情集中展示。
- 颜色：深森林绿 + 米白，严格贴近参考图。
- Codex 元素：不需要显性添加。

> 执行口径：高度复刻参考图的形态、色彩、设定稿结构和参数表达，但最终制作为“格物页”项目资产，不直接把原图像素搬运为成品。

## 3. 角色设定

- 名称：格物页
- 性格：话痨、调皮、鼓励型、专业。
- 说话风格：工作陪伴。
- 代表语：我在这儿，慢慢来。
- 角色气质：安静陪伴但不沉闷，像一个会鼓励用户推进工作的桌面小伙伴。

## 4. 第一版动作需求

### 基础动作

- 待机呼吸
- 眨眼
- 左右晃动
- 睡觉
- 鼠标 hover 时抬头
- 点击时开心
- 拖动时挣扎/摇晃

### 情绪动作

- 开心
- 困惑
- 生气
- 委屈
- 得意
- 紧张
- 专注
- 睡着
- 摸鱼

## 5. 交互需求

第一版 Demo 和后续桌面应用需覆盖或预留：

- 可拖动
- 可点击
- 右键菜单
- 悬浮在所有窗口上方
- 透明背景
- 可以隐藏/唤出
- 贴边停靠
- 靠近鼠标会看向鼠标
- 定时说一句话
- 根据状态切换表情
- 可以接入 Codex / CLI 状态
- 可以打开一个聊天气泡

## 6. 技术路线

用户选择：先不定技术，先做设计和 Demo。

第一版建议交付：

1. 角色设定图与动作帧资产。
2. HTML/CSS/JS 可交互 Demo，用于确认动作和交互。
3. Electron 框架草案，用于后续实现真桌面透明窗口、置顶、右键菜单和状态保存。

## 7. 窗口与显示

- 尺寸：可缩放。
- 默认位置：右下角，可移动。
- 背景：最终必须是真桌面透明窗口。
- 第一版网页 Demo：使用透明/棋盘背景模拟，后续 Electron 封装为真实透明窗口。

## 8. 音效

需要：

- 点击轻微音效
- 成功提示音
- 失败提示音
- 睡觉呼噜声

第一版 Demo 使用 Web Audio 生成轻量模拟音效，不依赖外部音频文件。

## 9. 状态与记忆

需要记忆或状态系统。第一版建议保存：

- 角色位置
- 角色缩放比例
- 当前情绪状态
- 是否静音
- 是否显示气泡
- 最近一次互动时间
- 贴边状态

Web Demo 使用 `localStorage`；桌面版使用本地 JSON 状态文件。
