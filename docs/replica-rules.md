# 格物页桌宠 1:1 复刻规则

## 原则

本 Demo 的角色外形必须严格来自用户提供的参考图：

- 参考图：`assets/reference/reference.png`
- 运行素材：`assets/legacy-disabled/*.png`
- 素材清单：`assets/legacy-disabled/legacy-disabled-manifest.json`

禁止重新设计、AI 再生成、CSS 重画或替换为相似风格角色。

## 必须保持

- 原始卷页/纸张造型
- 原始身体比例与边缘轮廓
- 原始面部位置、圆眼、腮红和嘴型风格
- 原始配色、阴影、纸张纹理和标注信息
- 参考图中已有的角度、表情、尺寸关系

## 允许的运行层处理

仅允许以下不改变外形的桌面运行处理：

- 等比缩放整张参考素材
- 直接裁切参考图中已有区域
- 切换不同参考图裁切区域
- 拖动、悬停、点击、右键菜单等桌面交互
- 透明桌面窗口承载

## 禁止事项

- 不得用 CSS 拼出新的宠物身体、眼睛、嘴巴或四肢
- 不得使用生成图覆盖参考图
- 不得添加参考图没有的装饰、底座、水印、标签
- 不得改变轮廓、比例、颜色或表情结构
- 不得凭想象补全参考图里没有的角度或动作

## 当前实现

当前 Demo 使用 `assets/legacy-disabled/sheet-full.png` 作为默认严格参考图模式；其它裁切素材仅用于展示参考图中已有区域，不代表新设计。
