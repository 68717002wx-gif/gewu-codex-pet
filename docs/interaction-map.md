# 格物页交互与状态映射

## 角色定位

- 名称：格物页
- 性格：话痨、调皮、鼓励型、专业
- 场景：工作陪伴
- 核心口头禅：我在这儿，慢慢来。

## 基础动作

| 动作 | Demo 表现 | 后续真帧建议 |
|---|---|---|
| 待机呼吸 | CSS 呼吸缩放 | 6-8 帧循环 |
| 眨眼 | 眼睛高度动画 | 2-3 帧闭眼过渡 |
| 左右晃动 | idle 摇摆 | 6 帧左右摆动 |
| 睡觉 | 状态切换 + 呼噜音 | 闭眼、气泡 Zzz、轻微起伏 |
| hover 抬头 | hover class 抬升 | 头部/眼神向上 |
| 点击开心 | happy 状态 + 成功音 | 眼睛弯月、腮红增强、跳一下 |
| 拖动挣扎 | dragging class 摇晃 | 手脚乱晃、身体倾斜 |

## 情绪动作

| 情绪 | 触发 | 语气 |
|---|---|---|
| 开心 | 点击/成功 | 鼓励、夸赞 |
| 困惑 | 状态按钮 | 帮用户拆问题 |
| 生气 | 失败/报错 | 调皮吐槽但不攻击 |
| 委屈 | 状态按钮 | 柔和陪伴 |
| 得意 | 完成任务 | 有点臭屁 |
| 紧张 | 拖动/风险 | 提醒稳住 |
| 专注 | 工作模式 | 专业、简洁 |
| 睡着 | 睡眠 | 呼噜声 |
| 摸鱼 | 休息提醒 | 调皮但可控 |

## 右键菜单建议

- 状态：待机、开心、专注、睡觉、摸鱼
- 行为：贴到右下角、窗口置顶、隐藏 3 秒
- 系统：打开设置、退出

## Codex / CLI 状态接入预留

建议后续把 CLI 状态归一为：

```json
{
  "type": "codex-status",
  "state": "running | success | failed | waiting_input",
  "message": "当前任务摘要"
}
```

映射建议：

- running → 专注
- success → 开心 / 得意
- failed → 生气后转鼓励
- waiting_input → 困惑 / 抬头看鼠标
